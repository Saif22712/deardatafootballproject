# Dear Data 100 - Football Passes

# 

# This is my Processing sketch for the Dear Data 100 coursework. It draws football passes as circles on a graph.

# 

# Each circle is one pass. the circle is where the pass ended, using the End X and End Y numbers and they both go from 0 to 100 . A green circle means the pass was successful and a red circle means it was not. The sketch shows the first 25 passes from my data so pass 1 to pass 25.

# 

# The data

# 

# My data is about football passes. For each pass I have where it started and also where it ended and if it worked or not. The positions are on a 0 to 100 grid of the pitch.

# 

# The data files in this repository are:

# \- football\_passes\_first30.xlsx - the first 30 passes as an Excel file

# \- football\_passes\_first30.csv - the same 30 passes as a CSV file

# 

# How I collected the data: i collected this data by watching my football clips assessing where 100 times i passed which so far i have done 30. now i get all the data and put it into my code and allocate each pass roughly where i actually passed it on the clip using coordinates. its a rough estimation

#
